Froala Editor — Video Feature Demo

A self-contained page for exploring how videos work inside the Froala rich text editor.

Try it out:
  1. Click inside the editor below.
  2. Click the video icon in the toolbar (looks like a small film strip / play button).
  3. In the dialog, either:
    • Paste a video URL (YouTube/Vimeo link), or
    • Paste an embed code, or
    • Upload a video file from your computer (stored temporarily in browser memory for this demo — see note below).
  4. Once inserted, click the video to see resize handles and the alignment/wrap options.

Note: This demo uses videoUploadURL pointing nowhere real, so file uploads in this sandbox will fail — that part needs a real backend (see the .NET/PHP/etc. server guides in Froala's docs). URL and embed-code insertion, resizing, and responsive behavior all work fully offline, right in this file.

⚠️ Avoid "Error 153: Video player configuration error"
If you double-click this file and it opens as a file://... URL, YouTube may refuse to load embedded videos because no referrer/origin header is sent from local files — that's the exact error shown in the "Video player configuration error" screen. To avoid it entirely, serve this file over a local server instead of opening it directly:
  • If Python is installed: open a terminal in this file's folder and run python3 -m http.server 8000, then visit http://localhost:8000/froala-video-feature-demo.html
  • Or use the VS Code "Live Server" extension, or any other local static server
This gives the page a real http:// origin, which YouTube accepts.
Editing an existing video (already inserted, like the sample below): click once on the video to select it — a floating popup appears with buttons to Replace it, Remove it, change Display (block/inline) or Alignment, set an exact Size, or toggle Autoplay. You can also just drag the square handles on its corners/edges to resize it freely, or drag a new video file from your desktop straight onto the editor to swap it in.
